What I Did

Designer & Artist Tools

  • Built a preset Mallow placement tool and trigger-based tutorial prefabs, so level designers could set up tutorial moments and dialogue in the Inspector without writing code.
  • Exposed Mallow speed and jump values as Inspector sliders and packaged NavMesh surface setup into components, so designers could tune platformer feel and bake NavMesh themselves.

Mallow AI & Gameplay Systems

  • Programmed the AI states for the ally Mallow characters and hooked up their animators.
  • Built Mallow–hazard interactions and the related respawn / despawn systems.

Art Pipeline

  • Created Mallow animator controllers, state-based expression material lists, and a single VFX script, so artists could drop assets into a structure that matched the agreed design.
  • Connected SFX and VFX to gameplay events.

UI

  • Designed screen flows, HUD layouts, and transitions as Miro mockups, then rebuilt and implemented all of the UI in Unity.

UI visual art by teammate Rodrigo.
